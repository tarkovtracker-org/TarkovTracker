## CI Job Pattern Comparison

Most CI jobs install only the root project. The Workers job installs root + worker sequentially.
Under pnpm workspace, a single `pnpm install` covers both root and worker.

| CI Pattern | npm Median (ms) | pnpm Median (ms) | Improvement |
|---|---|---|---|
| Typical root job (root-warm-scripts) | 22652 | 9429 | 58% |
| Workers job (root+worker warm-scripts) | 25032 | 9429 | 62% |
| Typical root job (root-warm-no-scripts) | 19205 | 3307 | 83% |
| Workers job (root+worker warm-no-scripts) | 21474 | 3307 | 85% |

## Disk Usage Notes

Disk measurements are **node_modules apparent size** (`du -sb`) only.
They do not include the pnpm store, npm cache, or GitHub cache archive size.
For developer disk footprint, add the incremental package-manager cache/store growth.
For CI, installation duration is more important than post-install directory size.
